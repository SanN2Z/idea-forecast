# 例子：用 lineage 路线"事后重演"一条公开脉络（RLHF → DPO，2022–2023）

这是一个教学用的示范，材料全部来自公开论文，用来展示每一步的产物长什么样。把"as_of"设在 2023 年 3 月，看这套流程能否在 DPO（2023-05）出现之前推出它的形态。

## 门 0 本地索引
项目里已引用 InstructGPT（2203.02155）、Constitutional AI（2212.08073）、RLHF 综述若干。这些不能在后面当"新发现"。

## F1a 引用骨干（节选）
| id | 一句话 | 默认前提 | 测量到的数字 |
|---|---|---|---|
| 2203.02155 InstructGPT | SFT → 训奖励模型 → PPO | 偏好必须先压成一个标量奖励模型 | 1.3B 对齐后人类偏好胜过 175B 基座 |
| 1706.03741 Deep RL from human preferences | 从成对比较学奖励再做 RL | 奖励与策略分两阶段 | ~900 次比较学会后空翻 |
| 2204.05862 HH-RLHF | 有帮助与无害的偏好数据 | 同上 | 数据规模与胜率曲线 |
| 2212.08073 Constitutional AI | 用模型自评替代部分人类标注 | 仍走 RM + RL | 无害性提升、有帮助性不降 |

## F2 归纳（只写已测量的事实）
1. 对齐增益主要来自偏好数据，不来自 RL 算法本身（多篇消融：换 RL 算法差异小于换数据）。
2. PPO 阶段不稳定、超参敏感、需要四个模型副本同时在显存里（多篇复现报告）。
3. 奖励模型会被过度优化（reward hacking），KL 约束是标配。

## F3 前提表与极限证据（节选）
| 前提 | 极限证据 | 否定后的世界 |
|---|---|---|
| 偏好必须先压成标量奖励模型 | 奖励模型过优化在所有规模上出现（2210.10760 的缩放律） | 直接在偏好对上优化策略，奖励隐式存在 |
| 需要在线 RL 采样 | PPO 的不稳定与显存开销不随工程改进消失 | 离线、监督式的目标函数 |
| 对齐 = 最大化奖励期望 | 期望最大化必然奖励黑客 | 目标改为"偏好对的分类损失 + 参考策略约束" |

## F4 新形态与第一个实例
新形态一句话：**把 RLHF 的 RM + PPO 两阶段合并成一个直接在偏好对上做的分类式损失，参考策略当 KL 锚。**
第一个实例：在 HH-RLHF 上，SFT 模型 + 新损失 vs SFT + RM + PPO，主量为 GPT-4 判定的胜率，判据是不劣于 PPO 且训练显存减半。

## F1b 近 90 天查空位（as_of 2023-03）
近邻检索目的是"有没有人已经在两阶段前提之外工作"：命中 SLiC（2210.00045，序列似然校准）、RRHF（2304.05302，排序损失）。差值：都改了损失，但没有把奖励模型与最优策略的解析关系写出来，也没有参考策略 KL 锚的闭式推导。

## 门 3 近邻差值表（节选）
| 近邻 | 做了什么 | 与候选的差值 | 类型 |
|---|---|---|---|
| SLiC-HF | 序列似然校准 + 正则 | 无 RM ↔ 策略的闭式对应 | 接合 → 整合型 |
| RRHF | 多候选排序损失 | 同上；无参考策略约束 | 接合 → 整合型 |
| PPO-based RLHF | 两阶段 | 候选去掉了 RM 与在线采样 | 新对象 → 可立项 |

## 门 4 杀伤测试
前提已测（RM 过优化缩放律已有）；构件即构念（"无 RM"必须是真的不训 RM，而不是把 RM 藏进损失里，需写清隐式奖励的定义）；骨架已有（SLiC/RRHF 的实验骨架可复用，只报新增的闭式推导与稳定性对比）；可检出（胜率差 ≥5 点在 HH 上可检）；最便宜证伪（先在小模型上比显存与稳定性）。四项过。

## 结果（事后对照）
2023-05 的 DPO（2305.18290）正是这个形态。这个重演说明 lineage 路线在"前提 → 极限证据 → 否定"这一步上有区分度：它推出的是"去掉 RM 与在线采样"这个对象，而不是"换一个更好的 RL 算法"这个格子。
